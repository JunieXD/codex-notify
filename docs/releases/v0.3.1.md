# v0.3.1 更新公告

> 发布日期：2026-08-10

本次更新加入内置安全升级能力：以后可以一条命令检查并安装新版本，升级异常时会自动恢复原有安装。

## ✨ 新增功能

- 现在可以运行 `codex-notify update` 升级，或使用 `codex-notify update --check` 只检查新版本。
- 现在可以用 `--version vX.Y.Z` 安装指定版本；默认不会降级，只有明确加上 `--force` 才会安装旧版本。

## 💡 体验优化

- 重新运行 curl 或 PowerShell 安装命令时，会自动识别已有安装并使用同一套安全升级流程。
- 替换程序前会校验 SHA-256、下载大小和目标版本，避免安装不完整或不匹配的文件。
- 升级会保留飞书凭据、原有通知链和已记录的多套 Codex 配置，无需重新执行 `init`。
- 升级期间会安全停止并恢复后台 watcher；任一步骤失败都会尽量恢复旧程序和后台服务。

## 📦 安装与升级

### macOS 与 Linux

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

从 v0.3.0 升级到 v0.3.1 时，请先重新运行对应平台的安装命令。升级到 v0.3.1 后，今后可直接运行 `codex-notify update`。首次安装完成后仍需运行 `codex-notify init`。
