# v0.2.0 更新公告

> 发布日期：2026-08-09

这是 `codex-notify` 的首个公开版本：让 Codex 在后台工作，完成或中断后通过飞书及时告诉你。

## ✨ 新增功能

- Codex 任务完成后自动发送飞书卡片，展示任务标题、耗时、原始任务和完整结果。
- 支持任务中断提醒，可识别网络断开、服务异常和用量限制等终止情况。
- 提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，无需安装 Rust。
- 提供 `init`、`test`、`status`、`doctor` 和 `uninstall` 命令，覆盖配置、检查与移除流程。

## 💡 体验优化

- 飞书卡片针对手机通知优化，重要状态一眼可见，任务与结果默认折叠展示。
- 中断事件会先等待任务是否自动恢复，减少短暂网络波动造成的误报和重复提醒。
- 后台 watcher 会在用户登录后自动启动，并以增量方式读取本地记录，保持较低资源占用。
- 安装时保留已有的 Codex notifier，卸载后可恢复原配置。

## 🛠️ 问题修复

- 完善 Windows 非管理员安装、系统凭据保存和登录自启，避免依赖管理员权限。
- 修复卸载后可能留下空 Hook 配置的问题，只清理由本工具创建的内容。
- 加强配置备份与归属检查，降低覆盖用户原有 Codex 设置的风险。

## 📦 安装与升级

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init`；已有用户重新运行安装命令即可升级。
