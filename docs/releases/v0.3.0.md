# v0.3.0 更新公告

> 发布日期：2026-08-10

本次更新新增 Linux 发行版，并让 `codex-notify` 在 Computer Use 与多套 Codex 配置之间保持稳定、可恢复的通知链。

## ✨ 新增功能

- 现在支持 Linux ARM64 与 x64，通过 systemd 用户服务在登录后自动运行后台 watcher。
- 现在可以与 Computer Use 稳定共存：Computer Use 保持在通知链最外层，不会形成重复调用。
- 现在会自动适配 `config.toml` 切换和符号链接配置，每套配置都保留自己的原有 notifier；也可运行 `codex-notify sync` 立即同步。

## 💡 体验优化

- Linux 上的 App Secret 使用桌面 Secret Service 安全保存，无需管理员权限，也不会写入明文配置。
- 后台 watcher 会持续检查当前配置，并在卸载前安全退出，减少配置切换与卸载同时发生时的冲突。

## 🛠️ 问题修复

- 修复重复执行 `init` 失败时可能拆除旧通知链的问题；升级失败后会恢复原配置与可用的后台服务。
- 卸载时会分别恢复所有已管理配置的原有 notifier，同时保留 Computer Use。
- 即使 `codex-notify` 本地配置暂时缺失，托管通知命令仍会继续调用原有 notifier，避免通知链被截断。

## 📦 安装与升级

### macOS 与 Linux

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init`。已有用户重新运行安装命令，再执行一次 `codex-notify init`，即可启用新的通知链与后台服务。
