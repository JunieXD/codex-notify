# v0.3.2 更新公告

> 发布日期：2026-08-10

这次更新重做了首次配置向导，让每一步都更清楚，填错内容也不必重新开始。

## 💡 体验优化

- `codex-notify init` 现在使用完整的中文分步引导，并说明 App ID、App Secret 等信息在哪里获取。
- App Secret 输入时会隐藏内容，提交后会明确提示已经收到且不会写入配置文件。
- 接收方式改为方向键选择，并为邮箱、Open ID、User ID 和群聊 ID 提供直观说明；首次使用默认选择最容易上手的邮箱。

## 🛠️ 问题修复

- App ID、邮箱或其他接收者信息填错时，现在会在当前步骤提示并允许重新输入，不再直接结束整个初始化流程。
- 切换接收方式时不再沿用其他类型的旧接收者信息，避免把邮箱误当成 Open ID 等常见混淆。

## 📦 安装与升级

已有用户可以直接升级：

```sh
codex-notify update
```

首次安装或需要重新运行安装脚本时：

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init`。
