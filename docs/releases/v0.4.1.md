# v0.4.1 更新公告

> 发布日期：2026-08-10

新会话的首条通知现在更容易显示正确标题，同时上线了更清晰的中文文档站。

## ✨ 新增功能

- 新增在线文档站，可以集中查看快速开始、命令说明、升级方法、问题排查和隐私安全信息。
- 新增飞书应用分步教程，第一次创建机器人也能按步骤完成权限、凭证和接收者配置。

## 💡 体验优化

- README 精简为项目概览和常用入口，详细说明移入独立文档，查找信息更加方便。

## 🛠️ 问题修复

- 新建 Codex 会话首次完成任务时，如果标题尚未生成，现在会按当前会话精确等待，最长 5 秒，减少通知显示“Codex 会话”的情况；已有标题不会增加等待时间。

## 📦 安装与升级

### 已安装用户

```sh
codex-notify update
```

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

首次安装完成后运行 `codex-notify init`；也可以重新运行对应安装命令完成升级。
