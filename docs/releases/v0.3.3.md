# v0.3.3 更新公告

> 发布日期：2026-08-10

这次更新让初始化的最后一步更顺手，并补全了 ChatGPT App 的 Hook 信任指引。

## 💡 体验优化

- “确认写入配置并启动后台监听”现在默认选择“是”，确认摘要后按回车即可继续。
- 初始化完成后会分别说明 ChatGPT App（原 Codex App）和 Codex CLI 的操作方式，帮助你正确信任 `UserPromptSubmit` 与 `Stop` Hook。

## 📦 安装与升级

已有用户可以直接升级：

```sh
codex-notify update
```

首次安装或需要重新运行安装脚本时：

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init`。
