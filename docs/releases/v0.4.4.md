# v0.4.4 更新公告

> 发布日期：2026-08-10

完成通知现在由后台可靠发送：新会话能等到真实标题，升级前已经打开的会话也无需重启 ChatGPT。

## 新增功能

- watcher 现在会从本地任务记录补获正常完成事件。即使任务在安装或升级前已经打开，后续完成时也能发送通知。

## 体验优化

- `notify` 收到完成事件后会快速写入本地队列，不再等待标题或飞书网络请求。
- watcher 会在后台等待新会话标题，最长 5 秒；发送暂时失败时会保留事件并稍后重试。

## 问题修复

- 修复新会话首条通知经常显示“Codex 会话”的问题。
- 修复旧会话没有加载最新 `notify` 配置时可能漏发完成通知的问题。
- 同一个任务从 `notify`、本地记录或 Stop Hook 到达时会按 turn ID 去重，不会重复发送。

## 安装与升级

已有用户可直接升级：

```sh
codex-notify update
```

升级会自动重启后台 watcher，无需重新运行 `init`，也无需重启 ChatGPT。

首次安装可使用以下命令。

### macOS 与 Linux

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init` 开始配置。
