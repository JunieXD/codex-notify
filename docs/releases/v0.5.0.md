# v0.5.0 更新公告

> 发布日期：2026-08-11

消息平台配置和凭据现在统一保存在一个本地文件中，安装与迁移更简单，也为后续扩展更多通知平台做好了准备。

## 新增功能

- 新安装会把飞书设置和 App Secret 统一写入 `~/.codex-notify/config.toml`，不再读取或依赖系统凭据库。
- 配置采用版本化的命名平台实例结构，为后续增加其他消息平台和同一平台的多个账号预留了空间。

## 体验优化

- macOS、Windows 和 Linux 现在使用相同的 `~/.codex-notify` 目录，配置更容易查找、备份和迁移。
- 从旧版本升级时会自动读取一次原有凭据、备份旧配置并转换为新版格式；迁移完成后不再访问系统凭据库。

## 重要变化

- App Secret 会明文保存在 `config.toml` 中，请不要提交、同步或分享这个文件。Unix 系统会将目录和配置文件权限分别限制为 `700` 和 `600`。
- macOS 用户从旧版本首次升级时，可能仍会看到一次钥匙串读取授权；这是旧凭据迁移所需，后续版本不会再次访问钥匙串。

## 安装与升级

已有用户可直接升级：

```sh
codex-notify update
```

首次安装可使用以下命令。

### macOS 与 Linux

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

安装完成后运行 `codex-notify init` 开始配置。
