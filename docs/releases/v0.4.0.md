# v0.4.0 更新公告

> 发布日期：2026-08-10

这次更新会主动识别已有配置，并让初始化、检查和升级过程都使用清晰易懂的中文提示。

## 💡 体验优化

- 再次运行 `codex-notify init` 时，会先显示不含密钥的当前配置，并默认保留退出；只有明确选择“重新配置”才会继续。
- 重新配置前会说明替换范围，并自动备份原 codex-notify 配置；已有 Codex 通知命令和其他 Hook 仍会保留。
- 命令帮助、状态、检查、同步、升级、卸载、安装脚本和错误提示均已改为中文。
- 飞书通知中的任务耗时现在使用中文显示；命令参数和 `--json` 键名保持不变，现有脚本无需调整。

## 🛠️ 问题修复

- 修复重复运行 `init` 会直接进入配置向导、容易让人误以为尚未配置的问题。

## 📦 安装与升级

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/JunieXD/codex-notify/main/scripts/install.ps1 | iex
```

已有用户可以直接升级：

```sh
codex-notify update
```

首次安装或需要重新运行安装脚本时，可使用上面的命令。安装完成后运行 `codex-notify init`。
